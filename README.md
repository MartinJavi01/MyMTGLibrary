# MyMTGLibrary
This project will allow you to keep track of all your mtg cards with a user-friendly UI and MongoDB as your DB.

## Requirements
To start this application you will need a java running environment (JRE) that allows you to run applications with JDK 17 or higher (just install the latest one and you are good to go).

Other requirement is to have a local instance of MongoDB at your localhost port (27017).
